# 0002 바깥 노출은 관문 하나로, 여는 경로를 목록으로 정한다

## 맥락
user 는 자기 상태 점검 경로를 인증 없이 열어 두고, 무거운 일정 생성 요청에 자체 호출 상한이 없다. 서비스 포트를 그대로 열면 지표가 새고 생성 한도가 남용된다.

## 선택지
1. 각 서비스 포트를 열고 서비스마다 막는다.
2. nginx 관문 하나만 열고, 여는 경로를 목록으로 정한다.

## 결정
2. 모든 포트는 `127.0.0.1` 에만 붙이고, 공개 관문(:8090)이 `/api/v1`·`/ws/chat`·`/ws/vision` 만 넘긴다. 그 밖은 404, `/actuator` 는 막고, 일정 생성·초대 경로에는 주소당 상한을 건다. 서비스끼리는 내부 창구(:8081)로 부른다.

## 결과
- 새 경로를 열려면 관문 설정을 고쳐야 한다. 그 대신 실수로 열리는 경로가 없다.
- 상대 컨테이너를 바꿔도 내부 창구 주소는 그대로라 무중단 교체가 관문의 상류만 돌리면 된다(0005).
