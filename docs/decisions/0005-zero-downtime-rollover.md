# 0005 서비스 하나를 요청을 끊지 않고 바꾼다 (교육용 도구)

## 맥락
컨테이너를 다시 만드는 동안 그 서비스로 가는 요청은 실패한다. 서비스끼리도 서로 부르므로, 부르는 쪽보다 불리는 쪽을 먼저 바꾸면 그 사이 호출이 깨질 수 있다.

## 선택지
1. 점검 시간을 두고 한꺼번에 다시 만든다.
2. 옆 컨테이너를 새 이미지로 띄우고 관문의 상류를 잠시 돌린 뒤 정식 컨테이너를 바꾼다.

## 결정
2. `scripts/service-rollover.py` 가 옆 컨테이너 → 상태 확인 → 관문 상류 교체 → 정식 컨테이너 재생성 → 상류 복귀 → 옆 컨테이너 정리 순으로 바꾼다. 마이그레이션은 확장만 허용한다(`scripts/migration-expand-gate.py`) — 교체 동안 옛 판도 같은 DB 를 쓰기 때문이다. `scripts/zd-probe.py` 가 교체 동안 공개 경로를 초마다 물어 실패를 센다.

## 결과
- 받아 쓰는 이미지는 우리 서비스 이름과 고정 다이제스트를 요구한다(움직이는 태그로는 바꾸지 않는다).
- 빠른 시작에는 쓰이지 않는다. 같은 기계에 여유 메모리가 있어야 한다(옆 컨테이너가 잠시 함께 돈다).
