# 0003 서비스마다 받는 환경변수를 목록으로 정한다

## 맥락
한 `.env` 에 모든 서비스의 비밀값이 모인다. `env_file` 로 통째로 넘기면 한 서비스가 뚫렸을 때 다른 서비스의 비밀값까지 함께 샌다.

## 선택지
1. `env_file: .env` 로 모두 넘긴다.
2. compose `environment:` 에 서비스마다 이름을 적고 그 이름만 넘긴다.

## 결정
2. 이름 체계는 여러 서비스가 같은 값을 읽으면 `MAP_PROJECT_`, 한 서비스만 읽으면 그 서비스 접두다. 같은 이름이라도 서비스마다 따로 정하는 값은 나눈다.

## 결과
- 서비스가 새 설정을 읽으려면 compose 목록에도 이름을 더해야 한다.
- 렌더 시험(`tests/test_service_environment.py`)이 비밀값이 필요한 서비스에만 가는지 고정한다.
