# 0006 공개본은 로컬 실행 구성만 담는다

## 맥락
비공개 개발본에는 운영 클라우드 환경을 세우고 옮기던 도구(인프라 코드, 호스트 설정, 배포 수신기, 백업 전송, 이미지 릴리스 공급망)가 함께 있었다. 그 운영은 끝났고, 도구는 그 환경의 식별자와 날짜에 묶여 있다.

## 선택지
1. 운영 도구를 일반화해 남긴다.
2. 로컬 실행 구성만 남기고 운영 도구는 지운다.

## 결정
2. 공개본은 compose 두 스택, 관문, DB 준비 사슬, 시험 스택 격리 검사, 무중단 교체 도구(교육용), HTTPS 앞단 예시(`example.com` 자리표시), 직접 빌드한 이미지를 받아 쓰는 덧칠만 담는다. 운영 도구와 그 문서는 히스토리에서도 경로째 지웠다.

## 결과
- 운영 환경을 다시 세우는 방법은 공개본에 없다. 받아 쓰기 덧칠은 사용자가 직접 빌드해 올린 레지스트리를 적어야 한다.
- 기본값은 로컬 실행용이다(인증 꺼짐, 합성 LLM). 외부에 열기 전에 인증을 켜고 비밀값을 다시 만든다.
